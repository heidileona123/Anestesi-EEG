ANESTESI OG EEG – NETTSIDEPAKKE (flat, uten mapper)

Last opp ALLE filene i denne mappen som enkeltfiler til GitHub (Add file → Upload files):
  index.html              norsk versjon
  en.html                 engelsk versjon
  manifest.webmanifest    norsk app-manifest (installasjon på mobil)
  manifest-en.webmanifest engelsk app-manifest
  sw.js                   offline-støtte
  icon-192.png, icon-512.png, icon-512-maskable.png, apple-touch-icon.png, favicon-64.png   ikoner

Adresser etter at GitHub Pages er slått på (Settings → Pages → Deploy from a branch, main, / (root)):
  norsk:   https://heidileona123.github.io/Anestesi-EEG/
  engelsk: https://heidileona123.github.io/Anestesi-EEG/en.html

Installere på mobil: åpne adressen i Safari (iPhone) → Del → «Legg til på Hjem-skjerm»,
eller Chrome (Android) → meny → «Installer app».
